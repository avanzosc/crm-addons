This module adds a pivot analysis view for ``crm.claim`` records.
It provides many filters and group-by options (creation date, close date,
deadline, customer, responsible user, action type, category, stage, team,
company, priority, and more).

At this stage, the pivot is focused on record counting (number of claims).

Usage
=====

Go to ``CRM > After Sale > Claims`` and switch to the pivot view.

From the search panel, you can:

* Apply filters such as Open, Closed, Overdue, Deadline Today, or Unassigned.
* Group by customer, responsible, team, stage, category, action type,
  company, active, and date dimensions (month/day).
* Use the ``Measures`` menu with the default count measure.
