==============
CRM Claim Menu
==============

This module adds a top-level **Claims** application to access 
existing CRM claims directly. It depends on the OCA's ``crm_claim`` 
module.

The menu opens the standard ``crm_claim.crm_claim_category_claim0`` action.
It reuses the existing claims, views, filters and access rules.
